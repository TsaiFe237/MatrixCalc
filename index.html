Тренажёр по матрицам

Вводи ответы в ячейки — они проверяются автоматически. Зелёный — верно, красный — ошибка. Можно писать дроби: 1/3, -7/2, а также через запятую: 0,5.
Матрица может быть прямоугольной (например 5×4) — тогда доступны только Гаусс и Транспонирование.

Метод Гаусса

Приводи матрицу (или расширенную [A|B]) к треугольному виду сложением / вычитанием строк. Работает для матриц любого размера m×n. Кнопка ↓ переносит строку из предыдущего шага (для 1-го — из исходной), сохраняя исходную запись (3/2 останется 3/2).
